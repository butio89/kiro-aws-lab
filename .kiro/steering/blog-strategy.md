# ブログ運営方針（Kiro × AWS ラボ）

このファイルは、当ブログの発信方針をまとめたものです。記事を作成・レビューするときの判断基準として使います。

## コンセプト

「AI開発ツール Kiro と AWS を使って、実際に作りながら学ぶ」技術ブログ。
作ったものがそのまま記事になる循環を目指す。

## 読者像（ペルソナ）

- 主読者: AWS を触り始めた〜中級のエンジニア。個人開発や学習中の人。
- 副読者: AI開発ツール（Kiro / Cursor / Copilot 等）に興味があるエンジニア。
- 読者の悩み: 「〇〇の作り方が分からない」「エラーが解決できない」「どのツール/教材を選べばいいか分からない」。

## 発信するテーマ（記事カテゴリ）

1. 制作記: 「Kiro で 〇〇 を作ってみた」系の体験談。一次情報になり最も価値が高い。
2. チュートリアル: 「Kiro × AWS Lambda/S3/DynamoDB でサーバーレス〇〇」など手順解説。
3. ツール解説: Kiro の spec/hooks/steering の使い方。
4. 比較・選び方: AI開発ツール比較、AWS学習教材の選び方。
5. トラブル解決: 実際に遭遇したエラーと対処法。

## 避けるテーマ

- YMYL（健康・金融・法律など）は扱わない。
- 実際に試していない内容の憶測記事は書かない（一次情報を最優先）。

## 収益化の考え方

- 軸はあくまで「読者の課題解決」。売り込みは最小限。
- 相性の良い収益源: AWS/プログラミング系の講座（Udemy等）、技術書（Amazon）、開発ツール・SaaS・レンタルサーバー等の紹介。
- 露骨な広告はエンジニア読者に嫌われる。文脈に自然に溶け込む形でのみ紹介する。
