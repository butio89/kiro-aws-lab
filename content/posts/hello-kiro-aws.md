## はじめに

この記事は、AI開発ツール **Kiro** と **AWS** を使いながら、技術ブログを立ち上げていく過程を記録する最初の1本です。ブログのテーマは「実際に作りながら学ぶ」こと。作ったものがそのまま記事になる、という循環を目指しています。

## なぜ Kiro を使うのか

Kiro は spec や hooks といった仕組みで、開発ワークフローを構造化できるのが特徴です。この記事の下書きも、Kiro に構成を考えてもらいながら書いています。

- テーマを渡すと記事構成を提案してくれる
- 下書きを書いてくれる（最終的な確認は人間がやる）
- 定型作業を hook で自動化できる

## このブログの構成

依存ゼロの静的サイトとして作っています。Markdown を書いてビルドすると HTML になり、AWS の S3 + CloudFront にそのまま置ける形です。

```bash
# 記事を書いたらビルド
node docs/scripts/build.mjs
```
